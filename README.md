# stitchcsv

Stitch digests and csv fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/stitchcsv/

## Install / run

```bash
git clone https://github.com/theworker02/stitchcsv.git
cd stitchcsv
node src/cli.js
node --test
```
